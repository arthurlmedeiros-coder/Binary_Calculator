O que estamos aprendendo?


    

      Uma NFT real é um registro digital único associado a uma obra, item ou informação.
      Nesta atividade, vamos simular esse processo de forma segura e educativa.
    


    

      

        Arte digital
        É a imagem criada pelo aluno.
      


      

        Metadados
        São informações como nome, criador, turma, tema e data.
      


      

        Hash
        É uma impressão digital dos dados. Se algo muda, o hash muda.
      


      

        Token ID
        É um código único que identifica a NFT didática.
